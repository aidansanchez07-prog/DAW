# DAW — Desarrollo de Aplicaciones Web

Ejercicios y prácticas del ciclo formativo de DAW.

## Estructura

```
1-DAW/
├── Programacion/            Java (NetBeans/Maven) por unidades didácticas
│   ├── PSeInt/              Pseudocódigo
│   ├── UD2 … UD9            UD9: WebCRUDEmpleados y WebCRUDFutbol (JSP + BBDD)
└── Lenguajes-de-Marcas/     HTML, CSS, JavaScript y XML

2-DAW/
├── Desarrollo-Entorno-Cliente/    JavaScript
├── Desarrollo-Entorno-Servidor/   HTML y PHP
├── Despliegue/
└── Diseno/                        HTML y CSS
```

No se incluyen compilados (`target/`, `build/`), comprimidos (`.rar`, `.zip`), instaladores
ni la instalación de WordPress usada en Lenguajes de Marcas.
